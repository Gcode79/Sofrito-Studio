# SECRETS ARCHITECTURE
* This project uses Cloudflare Workers. Production secrets are securely encrypted at the edge. Do NOT attempt to read them via the `wrangler` CLI.
* For local context, testing, and API memory, ALWAYS read the `.dev.vars` file located in the project root.
* CRITICAL SECURITY: Never output the raw values from `.dev.vars` into terminal logs, Git commits, or client-side HTML/JS files.
